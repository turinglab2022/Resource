## 화면 설명
- 벡터마다 **x성분·y성분**(가로·세로 화살표)이 같이 보이고, 두 성분의 끝에서 벡터 끝점까지 **점선**이 이어짐
- 파랑 = A, 주황 = B, **초록 = 결과**
- 더하기: B 를 A 의 끝점으로 옮겨 그리고(연한 주황), A 시작점에서 거기까지가 합
- 빼기: A − B = A + (−B). −B 를 A 의 끝점에 그림
- 왼쪽 위 패널: 성분, 계산식, 크기(피타고라스 정리 √(x²+y²))
